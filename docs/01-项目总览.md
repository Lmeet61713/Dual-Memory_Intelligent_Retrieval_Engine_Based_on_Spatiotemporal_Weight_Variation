# Homer · 智能家居物品记忆助手 — 项目总览

## 一句话定位

**Homer 是一个"具身智能 + 双记忆检索 + 自反馈闭环"的家庭物品记忆助手**：通过双摄像头观察并记住每件物品的位置，用 LLM Agent 自然对话召回，并在用户纠错后自动修正记忆权重——系统越用越懂你。

## 30 秒自我介绍（面试开场直接用）

> "我做了一个叫 Homer 的家庭物品记忆助手。它用两个摄像头——一个俯视全局、一个移动特写——做 YOLO 双摄交叉验证，确认物品存在后记录位置、参照物和置信度；物品的活跃度用艾宾浩斯遗忘曲线动态加权，常用的物品越来越容易被找到。用户用自然语言问'我的水杯在哪'，后端是带三个工具的 LangChain Agent：查物品位置、查对话历史、处理纠错反馈。如果用户说'不对'，系统会从补偿队列弹出备选物品，同时用贝叶斯更新对答错的物品降权——形成'识别 → 记忆 → 检索 → 纠错 → 再学习'的完整闭环。"

## 核心亮点

| # | 亮点 | 一句话说明 |
|---|---|---|
| 1 | 双摄像头交叉验证 | 全局 + 移动双摄同时确认同名物品才写入记忆，降低单摄误检 |
| 2 | 艾宾浩斯遗忘曲线权重 | 物品显著性随使用频率动态变化：常移动的"记得牢"，长期不动的慢慢淡忘 |
| 3 | 乘法似然 × 贝叶斯先验检索 | 语义相似度（名称×特征×参照物）与活跃度（weight×confidence）联合排序 |
| 4 | 补偿候选队列 | 检索 Top-5 中后 4 个进 SQLite 队列，用户否定时直接弹下一个，无需重新检索 |
| 5 | 自反馈闭环 | 三类反馈（位置/记忆/画像错误）→ 贝叶斯修正 → 审计日志 → high_dispute 标记 |
| 6 | 五维动态用户画像 | 性格 / 兴趣 / 价值观 / 沟通风格 / 习惯，每 5 轮 LLM 抽取 + 锚点衰减奖励 |
| 7 | 物品使用习惯分析 | 按早 / 午 / 晚 / 深夜统计使用时段，注入 Agent 提示词 |
| 8 | 双端交互 | PC 端 SSE 流式聊天 + 移动端 WebSocket 实时通信 |

## 技术栈

| 层次 | 技术 |
|---|---|
| 前端 | Vanilla JS（index.html / mobile.html） |
| 后端 | Python 3.13 / FastAPI / Uvicorn / SSE / WebSocket |
| Agent | LangChain 1.x `create_agent` + LangGraph CLI / DeepSeek-chat |
| 向量 | BGE-small-zh-v1.5（SentenceTransformer）+ numpy |
| 视觉 | YOLOv8（ultralytics）双模型 + OpenCV |
| 存储 | JSON 文件（会话 / 空间 / 画像）+ SQLite（补偿队列） |
| 工具链 | uv 包管理 / LangSmith 追踪 |

## 关键数字

- 空间记忆：54 个家居物品（含坐标、参照物、特征、权重）
- Agent 工具：3 个（查位置 / 查历史 / 纠错弹备选）
- YOLO：全局模型约 6000 图训练 150 轮，移动模型 100 轮
- 市场调研：97 份有效问卷
- 召回率：静态数据测试约 92%（LangSmith 追踪）
- 反馈系统：21 个单元测试 + 10 个 HTTP 集成测试全部通过
- 服务端口：8501（PC 端 / 移动端 `/mobile`）
