# 完整交互流程

## 主线一：感知链路（摄像头 → 空间记忆）

```mermaid
sequenceDiagram
    participant GC as GlobalCamera 俯视
    participant MC as MobileCamera 移动
    participant Y as YOLODetector 双模型
    participant MT as Matcher 每20秒
    participant CM as ConfidenceManager
    participant SM as spatial_memory
    participant HA as 习惯分析 每300秒

    loop 持续采集
        GC->>Y: 每 30 帧推理
        MC->>Y: 每 30 帧推理
        Y-->>MT: 检测框 + 置信度
    end
    MT->>MT: 同名 且 置信度 >= 0.4 双摄匹配
    MT->>MT: 提取附近 2 个参照物 距离 <= 200px
    MT->>CM: process_observation 坐标/置信度/参照物
    CM->>CM: 坐标变化 -> 移动奖励 / 静止 -> 步长+1 / 超20秒未观测 -> 消失衰减
    CM->>SM: 更新权重并同步向量
    CM->>HA: 记录轨迹
    HA-->>HA: 每 300 秒聚合时段习惯
```

## 主线二：对话链路（用户提问 → Agent → 检索 → 回答）

```mermaid
sequenceDiagram
    participant U as 用户
    participant FE as FastAPI 聊天接口
    participant PRE as 上下文预处理
    participant AG as LangChain Agent
    participant TOOL as 工具层
    participant SM as 空间记忆
    participant CB as 补偿队列 SQLite
    participant P as 画像与习惯

    U->>FE: 我的水杯在哪？
    FE->>PRE: 保存消息 / 话题分段 / 构造上下文
    PRE->>P: 注入画像 + 习惯摘要
    PRE->>AG: messages + 动态 system prompt
    AG->>TOOL: 调用 search_item_location
    TOOL->>SM: BGE 检索 Top-5
    SM-->>TOOL: Top-1 格式化 + Top2-5 入队
    TOOL-->>AG: 最优结果
    AG-->>FE: 流式自然语言回答
    FE-->>U: SSE / WebSocket 逐字渲染
```

## 主线三：纠错闭环（用户否定 → 备选 + 修正）

```mermaid
sequenceDiagram
    participant U as 用户
    participant AG as Agent
    participant FBT as 纠错工具
    participant CB as 补偿队列
    participant DISP as 反馈分发器
    participant CM as ConfidenceManager

    U->>AG: 不对，不是这个
    AG->>FBT: 调用 user_correction_feedback
    FBT->>CB: 按 position 弹出下一个候选
    CB-->>FBT: 备选物品
    FBT-->>AG: 返回备选
    Note over FBT,DISP: 同时异步触发
    FBT->>DISP: location_wrong 修正事件
    DISP->>CM: 贝叶斯降权 + feedback_history 审计
    AG-->>U: 那应该是…
```

## 状态与上下文传递

- `ToolContext`（contextvars）：session_id、all_messages、compensation_buffer_id、last_top1_item，跨工具调用传递
- 会话文件记录：messages、count_session、segment_start、interval_vec（话题区间状态）
- 回答保存：assistant 回复流式结束后写入会话 JSON；空响应 / 异常有兜底消息，保证 PC 与移动端消息完整
- 流式修复记录：`agent.stream(..., subgraphs=False)` 确保 LangGraph 1.x 下正确解构消息 chunk（详见 `.trae/documents/fix-sse-streaming-root-cause.md`）
