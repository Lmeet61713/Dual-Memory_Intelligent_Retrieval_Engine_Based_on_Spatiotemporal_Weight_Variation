# 模块与代码索引

> 面试官翻代码时对照这张表，10 秒定位每个功能。

## 应用层 application/

| 文件 | 职责 | 关键函数 / 类 |
|---|---|---|
| `web_ui.py` | FastAPI 入口、SSE 聊天、WebSocket 移动端、摄像头接口 | `_prepare_chat_context` / `_run_agent_stream` / `chat` / `mobile_websocket` |
| `data_exporter.py` | 会话 / 摘要 / 向量 JSON 读写 | `DataExporter` |
| `static/index.html` | PC 前端（流式渲染 + 3 类反馈按钮） | — |
| `static/mobile.html` | 移动端 WebSocket 页面 | — |

## Agent 层 Agent/

| 文件 | 职责 | 关键函数 / 类 |
|---|---|---|
| `agent.py` | 创建 LangChain Agent（deepseek-chat） | `get_agent()` |
| `tools.py` | 3 个工具定义 | `search_item_location` / `search_conversation_memory` / `user_correction_feedback` |
| `tool_context.py` | 请求级上下文 | `ToolContext` / `set_current_context` / `get_current_context` |

## 记忆层 memory/

| 文件 | 职责 | 关键函数 / 类 |
|---|---|---|
| `spatial_memory.py` | 空间检索（Top-5 + 语气分级） | `search_spatial_memory` / `format_spatial_result` |
| `semantic_memory.py` | 话题分段 + 摘要 + 向量召回 | `check_and_close_segment` / `semantic_retrieve` |
| `compensation.py` | SQLite 补偿队列 | `create_buffer` / `pop_next` / `cleanup_expired_buffers` |

## 决策层 decision/

| 文件 | 职责 | 关键函数 / 类 |
|---|---|---|
| `matcher.py` | 双摄匹配主循环 | `Matcher._match_and_update` / `_find_nearby_refs` |
| `confidence_manager.py` | 三线权重 + 反馈审计 | `ConfidenceManager.process_observation` / `apply_feedback_penalty` |
| `high_weight_reminder.py` | 高权重物品提醒 | `ReminderManager` |
| `personal/Peronal_manager.py` | 五维画像（文件名沿用原拼写） | `PersonalManager.update_and_get_summary` |
| `personal/item_habit_analyzer.py` | 时段习惯 | `ItemHabitManager.run_analysis` |

## 感知层 perception/

| 文件 | 职责 | 关键函数 / 类 |
|---|---|---|
| `camera_stream.py` | 摄像头线程采集 | `Camera` / `GlobalCamera` / `MobileCamera` |
| `yolo_detector.py` | YOLOv8 推理 + 坐标映射 | `YOLODetector.detect` |

## 反馈层 feedback/

| 文件 | 职责 | 关键函数 / 类 |
|---|---|---|
| `router.py` | POST /feedback + /stats + /graph | `submit_feedback` / `get_stats` / `get_graph` |
| `dispatcher.py` | 贝叶斯修正分发 | `bayesian_update` / `dispatch_correction` |
| `schemas.py` | Pydantic 数据模型 | `FeedbackRequest` / `FeedbackEvent` |
| `metrics.py` | 指标采集聚合 | `record_metric` / `get_stats` |
